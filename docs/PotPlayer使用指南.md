# 夸克网盘 PotPlayer 使用指南

在 PotPlayer 里直接浏览并在线播放自己的夸克网盘文件。不用先下载到本地，也不占磁盘缓存。

适用于 Windows 10/11 64 位 + PotPlayer 64 位。安装方式见[安装说明](PotPlayer安装说明.md)。

## 能做什么

- 在 PotPlayer 的媒体地址列表里浏览自己的夸克网盘目录，逐级进入子目录，可在目录间往返。
- 直接在线播放网盘里的原文件，支持暂停、拖动进度。
- 同一目录里的视频按“第2集、第9集、第10集”这样的自然顺序排列，选中某一集后会继续播放同目录的下一集（是否自动续播由 PotPlayer 的播放结束设置决定，插件不改动用户的全局设置）。
- 自动记住观看进度：从目录、搜索结果、最近观看或播放列表再次打开同一个视频时，会接着上次的位置继续播放。进度只保存在本机私有目录，和收藏/最近观看放在一起。
- 在“搜索网盘”里输入关键词，直接搜索整个网盘的文件夹和视频（支持中文）。
- 把常用目录放进“收藏目录”，随时一步进入；目录失效后也能取消收藏。
- 在“最近观看”里找回最近成功播放过的视频，也可以一键清空记录。
- 在“继续观看”里直接接着看未看完的视频；目录首屏还有“继续观看”和“剧集观看状态”两行，可按集标记已看/未看，已看的一集不会被自动续播。
- 在“追剧中心”里按真实的所在目录把本机最近观看过的视频（含已看完的）分组列出，进入分组可看“已看 x/y”，并接着播“下一集”；每条视频都有“操作”行，可打开“精彩标记”或“删除本条观看记录”——删除只在确认后移除这一条本机记录，不影响网盘文件、收藏、已看标记与精彩标记。
- 在 PotPlayer 原生的“字幕搜索”里列出当前视频**同目录**的匹配字幕（SRT/ASS），手动选择加载；内嵌字幕不受影响。
- 在“插件管理 → 精彩标记”页按剧集浏览标记，点“标记当前时间点”为正在播放的视频添加精彩标记：记录播放器的真实当前时间，备注可留空；之后可跳转、重命名或删除，精彩标记只保存在本机。
- 首次使用扫码登录一次即可，之后打开就能看到目录。

## 安装与首次登录

1. 关闭 PotPlayer，运行 `QuarkPotPlayer-Setup.exe`，按[安装说明](PotPlayer安装说明.md)完成安装。
2. 打开 PotPlayer，在浏览器面板的“打开菜单”中选择“简索 → 简索地址…”，展开左侧“打开地址”，选择“夸克网盘 我的网盘”浏览目录。搜索、收藏、最近观看与插件管理等入口也在这里。
3. 第一次会弹出扫码窗口：用手机夸克 App 扫描窗口里的二维码，并在手机上确认登录。
4. 扫码完成后目录会自动显示；若等待超时，重新进入一次该入口即可（登录已完成的会话立即显示目录）。

登录只需一次。插件使用自己的登录凭证，与 `quark` 命令行工具保存的登录状态互不影响：插件登录不会改动命令行的登录，命令行的退出登录也不会让插件掉线。

## 账号管理

从 PotPlayer 的“插件管理”打开“夸克网盘插件管理”，切到独立的“账号管理”标签页。

- **扫码添加账号**：用手机确认登录。添加完成后切到该账号；取消或失败保留原账号。
- **切换到所选账号**：复用已保存的登录凭证，其他账号保持登录，无需再次扫码。
- **退出所选账号**：仅清除该账号的插件凭证，不影响其他账号或 CLI 登录。本机观看数据保留，重新登录同一账号后可继续使用。
- **昵称与容量**：显示当前账号昵称、各账号最近查询的剩余容量和总容量。首次进入账号页会查询当前账号；之后可点“刷新当前昵称与容量”。每秒诊断轮询不查询云端容量。
- **数据隔离**：收藏、最近观看、观看进度、已看状态和精彩标记分别归属各账号，不按昵称或文件名合并。同名账号也分开保存。
- **切换后的播放**：旧播放流、播放列表、字幕选项及精彩标记窗口失效；从“我的网盘”等根入口重新打开目录和视频。旧请求不会写入新账号。

升级会将原有凭证与原有记录绑定；没有旧凭证时，无法确认归属的历史文件保留在原位置，不自动归给新登录账号。标准扫码凭证用稳定的用户标识区分账号；缺少该标识的导入凭证按凭证单独建档，可能出现额外账号记录，但不会与其他账号混合。

### 旧账号文件升级与错误隔离

0.10.1 支持旧版 `{current, accounts: [...]}` 账号文件。首次加载先在同目录写入私有 `accounts.legacy-backup.json`，再迁移两个账号的凭证及当前选择；已有账号专属观看记录保持原文件和归属。

如果账号文件确实损坏，账号页会明确显示错误并停止账号写入，原文件不会被空配置覆盖；播放诊断及精彩标记页面仍可独立打开，不再出现启动时的未处理异常。无法确认账号归属的记录不会分配给其它账号。

## 浏览目录

- 列表只显示**文件夹**和**可播放的视频文件**，其它文件（图片、文本、字幕等）不会出现在列表里，以免产生点不动的条目。
- 文件夹显示为目录项，进入后可以继续浏览；列表最上方的 `..` 返回上一级目录。
- 目录内容较多时会分页；继续向下翻即可加载后面的条目。
- 目录名和文件名中的中文正常显示。
- 目录首屏与观看状态共用一次完整目录读取；小目录不再为了“继续观看”重复请求。只有含视频的目录才出现“继续观看”“精彩标记”和剧集状态；文件夹行、图片和文本不提供视频标记操作。

## 搜索、收藏、最近观看与追剧中心

除“我的网盘”外，媒体地址列表里还有以下入口：

- **搜索网盘**：选中后在上方的搜索框输入关键词并回车，列出整个网盘里文件名匹配的**文件夹和视频**，支持中文；结果分页，继续向下翻即可。进入搜索结果里的文件夹后按目录正常浏览，可用 `..` 回到搜索结果页，结果页会按原关键词重新搜索。
- **收藏目录**：列出已收藏的文件夹，进入后与普通目录一样浏览、播放、选集。在任意非根目录的第一页，列表最上方有一条“收藏当前目录”（该目录已收藏时显示“取消收藏当前目录”）；选中它进入动作页，页面顶部有一条“已收藏当前目录 · 返回”或“已取消收藏当前目录 · 返回”的行（结果与返回合在一行，因为只有标题的行会被播放器过滤），选中它回到刚才的目录。这个动作是幂等的：重复刷新只会重复执行同一次收藏或取消，不会来回切换。网盘里已经删除或移动、打不开的收藏目录仍会列出，并且仍可直接取消收藏。收藏目录行还会附上该目录最近观看过的一集（“· 上次观看：…”），方便直接接着看。
- **最近观看**：按时间从近到远列出已经开始读取的视频（获取播放链接、HEAD 请求、未读取到数据的失败播放不计入；最多 100 条，同一文件只保留最近一次）。看了一部分后关闭播放器，记录仍保留。条目名称会带观看进度或“已看”标记，能确认所属目录时还带“目录名 / 原文件名”。选中某条会从该视频开始播放它所在目录的自然排序选集，之后可用上一集/下一集或自动下一集继续。每条视频下面还有一条“操作：…（精彩标记、记录）”文件夹行，进入后可“播放”、打开“精彩标记”管理窗口，或“删除本条观看记录”（先进入确认页，确认后只删这一条本机记录）。列表最上方有“清空最近观看”，进入动作页显示一条“已清空最近观看 · 返回”的行，选中即返回；重复执行不会报错（幂等），该入口与行为保持不变。
- **追剧中心**：分类名由“继续观看”改为“追剧中心”。根页面只读本地记录（`/v1/watch-center`，不联网、不扫盘），把本机最近观看过的视频（**含已看完的**）按**真实所在的非根目录 FID**分组：同一目录的视频合并成一条剧集分组，分组行显示“已验证的目录名 · 上次：<最近一集名> · 已看<百分比>”（目录名无法确认时用固定占位“来源目录未命名”），仍有未看完的集数时再附上（如“· 未看完 3 集”）；同名但 FID 不同的目录会分成多条，不按名字合并。根目录下或无法确认所属目录的视频各自单列，用原文件名（带进度）直接播放并附“操作”行。分组按最近一集的时间从新到旧排列。根页面是纯本地读取，不做后台扫描、也不为此访问夸克；记录仍来自本机“最近观看”（最多 100 条，很久以前被挤出记录的视频不再出现）。
- 进入某个分组会**只读取该目录一次**（远程 `GET /v1/series`），顶部显示“观看进度（已看 x/y）”（整目录看完时为“已全部看完（已看 x/y）”）。目录里每个视频都会列出（含已看完的），每集都可播放，并各带一条“操作：…（精彩标记、记录）”行；只有该目录清单完整、非空且每一集都已看时才显示为看完。分组页顶部还有“继续观看：…”（沿用本机保存的续播目标）与“下一集：<文件名>”（**本次目录清单**里最近观看那一集之后的下一集，名称与大小等元数据都取本次清单，标题带真实文件名以免与剧集行混淆）；最近的一集已是最后一集时显示“已到最后一集 · 返回”，**不会**回到第一集重播；该目录为空（或只有非视频文件）时只显示“该目录没有视频 · 返回”，**不**会误标“已到最后一集”或“已全部看完”。
- **精彩标记（快速入口）**：视频文件下方和“最近观看”“追剧中心”的单视频操作页均可打开精彩标记窗口。目录里的“精彩标记”入口只在该目录含视频时出现；根分类另有“精彩标记”，可查看全库标记并打开集中管理。
- **删除本条观看记录**：进入确认页，顶部有一条“确认删除本条观看记录（不影响网盘文件）”，选中后才真正删除；只删除这条视频的本机观看记录与续播点，其它观看历史、收藏、已看标记与精彩标记都不受影响，网盘文件也不会被删除。删除是幂等的：重复刷新只是重复同一个动作。**不会**跳转或停止播放，已经开始的会话继续播放，但删除后该视频的实时监控记录被抑制，不再把这条历史与进度写回——**只有再次显式播放才会恢复记录与进度写入**。
- **插件管理**：打开本机状态窗口，查看播放与请求状态、账号凭证与冷却情况，并可保存排查信息报告；无需登录即可打开（详见下文“插件管理”）。

搜索框留空、收藏为空或没有观看记录时，部分 PotPlayer 版本会显示“无法找到该文件”。输入关键词、收藏一个目录或开始播放视频后，重新进入对应入口即可看到内容。

## 播放、选集与下一集

- 打开一个视频即开始在线播放原文件，可拖动进度条跳转。
- 打开某一集时，PotPlayer 会把同一目录下的视频按自然顺序组成播放列表，从这一集开始；也可用上一集/下一集手动切换。是否在播放结束自动跳到下一集取决于 PotPlayer 的“播放结束后”设置，插件不会修改用户的全局设置。
- 播放列表里只包含视频文件；非视频文件不会混进来打断顺序。
- 内嵌字幕与音轨由 PotPlayer 原生解码与切换；同目录的外挂字幕按下一节手动选择，不提供影视海报或转码。

## 目录里的继续观看与剧集状态

含视频的非根目录首屏会提供以下入口；无视频时不显示。网盘根目录保持分页浏览，视频行仍可进入自己的精彩标记：

- **继续观看：…**：直接播放该目录里最近未看完的一集；如果都看完了，则选自然顺序里第一集未看的；整个目录都看完时显示“本目录已全部看完 · 查看剧集状态”，**不会**从头重播整季。
- **精彩标记**：列出该目录视频已保存的标记；也可从每个视频下面的“精彩标记：文件名”入口添加或管理。
- **剧集观看状态（已看 x/y）**：进入后逐集列出该目录的视频，未播放过的视频也会出现。点某一集可在“已看/未看”之间切换：
  - 标记“已看”后，该集不再自动续播，也不再出现在“继续观看”里；
  - 标记“未看”会清除该集保存的进度（只改本机记录，**不会**向正在播放的窗口发送跳转），之后真实播放进度可以重新记录；
  - 重复执行同一个标记不会重复改动（幂等）。
- 目录首屏、观看状态与收藏状态复用同一个完整目录快照，观看状态与进度只保存在本机；读取失败会显示目录错误，不会拿不完整的列表判断“全部看完”。
- “追剧中心”的分组页顶部“观看进度（已看 x/y）”也进入同一套“剧集观看状态”管理页，可逐集切换已看/未看。

## 播放进度与断点续播

- 播放时组件每 2 秒读取一次播放器进度，每 10 秒落盘一次，并在暂停、切换集数或关闭播放时各保存一次。
- 从**目录、搜索、最近观看、继续观看或播放列表**再次打开同一个视频时，会自动跳到上次保存的位置继续播放，并在提示行显示“已恢复上次观看位置”。被手动标记为“已看”的视频不续播。
- 刚开始不久就关闭的片段不打断下次观看：保存位置不足 15 秒时下次从 0 开始。
- 快看完时不再往回跳：剩余时长不超过 `min(30 秒, 总时长 2%)` 时，下次从 0 开始，并计入“已看”（标记为已看后也不再自动续播）。
- 播放器在组件首次读到进度时若已播放超过约 5 秒（例如你手动拖过），组件尊重播放器当前位置，**不会**把它强行拉回保存点。
- 文件大小或时长与保存时明显不符（被替换成另一个版本）时，不套用旧进度，从 0 开始。
- 识别对象是**播放器窗口进程（PID）与完整的逻辑文件地址**：组件只按“这个 PID 正在播这个 fid 的逻辑地址”核对，不使用文件名、窗口标题或下载字节数比例做判断。该 PID 由扩展调用随包启动器 `quark-potplayer.exe --player-pid` 就地取得（启动器只认拥有 PotPlayer 窗口的进程，验证不到就按无 PID 处理，不会误认其他播放器）。
- 同一个文件被多个播放器实例同时打开时，组件暂停该 fid 的进度记录与续播（避免互相覆盖），其中一个实例关闭后其余实例恢复正常记录。

这是 Windows 端 PotPlayer 的原生能力：其它平台的 CLI 不受影响，桥接在缺少该原生读取能力时仍可作为数据源使用。

## 插件管理

媒体地址列表里还有一个**插件管理**入口，用来在本机查看播放与请求状态。它不要求先登录，未登录、登录过期或处于冷却中都能打开：

- 选中后会在前台打开**夸克网盘插件管理**，依次为“账号管理 / 精彩标记 / 播放诊断 / 安装管理”，默认显示账号管理。窗口关闭不会停止播放；再次点击入口会恢复并带到前台，不重复创建窗口。扫码登录与独立精彩标记窗口也会在前台显示，均使用 PotPlayer 图标。
- 账号、诊断、标记三个页面分别访问本机 `127.0.0.1` 上各自的接口，使用独立请求线程；诊断与精彩标记每秒读取本地状态，账号页读取本地账号列表。刷新账号昵称和容量会访问夸克，但不阻塞诊断和本地标记操作，不主动进行探针、缓冲或码率探测。
- “播放诊断”先解释当前情况，例如正在播放、已暂停、未登录或需要等待；下载速度为 0 可能是暂停或已有足够缓存，不会据此直接判为故障。下面依次显示正在播放的视频、网盘连接、本次打开过的视频下载情况和最近遇到的问题；没有错误时明确显示“暂无问题记录”。选择正在播放的视频可“从头播放”。
- 下载速度为最近 5 秒平均值，已下载量为实际转发字节，重复拖动会重复计入；总量是本机服务本次运行的合计，各行分别统计每次打开的视频。网盘响应时间是最近一次下载请求等待响应头的时间，不是视频缓冲时长。
- 账号状态只来自实际发生过的请求，不能证明账号未被限制；组件也不会为此额外联网校验。
- 窗口内的“保存排查信息”会把一份经过白名单裁剪的报告另存为 UTF-8 JSON 文件（由你选择保存位置）。报告只含发布/协议/系统版本、聚合的传输统计、冷却与固定错误事件，**不含** Cookie、令牌、播放地址、fid、文件名、观看进度或绝对路径，也不会自动上传。
- “精彩标记”标签页直接显示已保存标记的剧集文件夹，双击进入后查看各集的时间点和备注；“返回剧集列表”回到外层。“标记当前时间点”弹出备注对话框，确认后记录播放器的**真实当前时间**；备注可留空，最多 200 字。无需先打开播放诊断或选择诊断会话。
- 视频未播放时也可从视频操作页打开管理窗口，查看、编辑备注和删除；选择标记点“跳转”会自动打开该视频并跳到标记位置。添加标记仍需该视频正在播放。
- 精彩标记只归属**当前这个视频**：按播放器窗口进程（PID）与完整逻辑文件地址核对，不能按标题或文件名猜。文件被换成不同大小或时长后，仍可对新文件**添加精彩标记**（记录新文件当前的真实时间点），但指向旧文件的已有精彩标记会因大小或时长不符而**跳转失败**；同一个文件被多个播放器实例打开、或本机没有原生读取能力时，不记录也不跳转（删除与重命名只改本机记录，仍然可用）。列表会在你切换选中视频、断开连接或关闭窗口后自动丢弃，迟到的结果不会被写到别的视频上。
- 精彩标记是按账号保存的**独立**本地小文件 `accounts/<账号标识>/bookmark.json`，与各账号的 `library.json` 分开；升级导入的原账号继续使用旧路径。**不会**出现在导出的诊断报告里；退出和过期均保留。

## 精彩标记与集中管理

原“书签”已统一更名为“精彩标记”。旧 `bookmark.json` 可直接读取；新增或补全目录信息时自动写为版本 3，时间点和备注保持原样。

1. 有视频的目录首屏只显示一个“精彩标记”管理入口，以及一个“标记当前时间点”动作，不再在每一集下面重复列出标记入口。顶部“精彩标记”只管理当前目录下所有视频的标记；点击后仅打开精彩标记窗口。最近观看/追剧中心的单集操作页仍可管理指定视频的标记。
2. 点击“标记当前时间点”，在弹出的备注框输入此处精彩的原因（可留空，最多 200 字）；取消不会保存。保存的是提交时播放器的真实时间点。目录入口仅对该目录中唯一正在播放的视频生效，多实例冲突时不可添加。
3. 选择一条标记，点“跳转”：同一视频正在播放时直接跳到标记位置；从视频入口或集中管理窗口操作、该视频尚未播放时，会自动打开 PotPlayer 中的该视频，待时长就绪后跳转。标记来自旧版本视频、大小或时长不匹配时不会强行跳转。
4. 在与“我的网盘”“搜索网盘”同一级的“精彩标记”入口，以及“插件管理 → 精彩标记”标签页，先按剧集文件夹展示全部已保存标记；双击剧集再查看各集的“视频 / 时间 / 备注”，可跳转、编辑备注和删除。相同名称但不同目录的剧集分别展示。此列表不受最近观看 100 条上限影响，也不会因删除观看记录而消失。
5. 新标记保存真实目录 FID 与名称。旧标记会利用本机已有最近记录、浏览过的目录或收藏目录补全；无法确认归属的保留在“未分类”，不按“01.mkv”等文件名猜剧集，也不扫描整个网盘。正常浏览原视频目录后，再刷新标记列表，可用这次目录清单补全旧标记归属。

查看、修改备注和删除只操作本机数据，可离线进行；自动打开网盘视频需要登录且请求未处于冷却。同一视频正在加载或被多个播放器实例同时打开时，等待加载完成或关闭重复实例后再跳转。

## 外挂字幕

- 播放视频后，右键打开菜单，选择“字幕 → 在线字幕搜索 → 下载字幕…”。在列表中选择来源为“夸克网盘字幕”的匹配项，然后点击“打开字幕”；“另存为…”和“直接保存”是播放器自己的保存操作。
- 播放夸克视频时，PotPlayer 原生的“字幕搜索”会列出该视频**同目录**里文件名匹配的 SRT/ASS：同名优先，允许常用语言后缀，季集按 `SxxEyy` 或“第N集”对齐，拒绝另一季、另一集或另一剧；中文候选优先。
- 列表项显示真实文件名，并把格式（srt/ass）与已知语言（zh/en）交给播放器；语言未知的文件也能列出。
- 这是**手动**流程：插件不会自动选中外挂字幕、不会替换内嵌字幕轨，也不改动你的全局字幕偏好。加不加载、加载哪一条都由你在播放器里决定；没有候选时内嵌字幕照常显示。
- 只有当前夸克视频才有候选：本地文件或其它来源的视频不会出现任何条目。
- 字幕文本由本机组件在内存中读取后交给播放器，插件不写字幕文件、不写视频文件。PotPlayer 自身是否把所选字幕保存到磁盘，由播放器行为决定，与插件无关。

## 缓存与隐私

- 播放是内存转发：不创建视频文件、不写分片、不建立磁盘视频缓存，只保留有限的播放缓冲。
- 播放整集或跨较大范围拖动时，组件会把要用的这段字节分成 4 MiB 一小段，从夸克**顺序**取回并立即转发给播放器（源站对一次性大请求会限速）。这只是边取边发，不是预下载，也不在本地落下任何文件。
- 组件的登录凭证保存在当前用户的私有目录中，和 `quark` 命令行工具的凭证分开存放。
- “收藏目录”“最近观看”“追剧中心”与“已看”标记都保存在同一个私有目录下的小 JSON 文件里（`library.json`，Windows 下为 `%APPDATA%\quark-drive-cli\potplayer\library.json`）。它只记录目录/文件的标识、名称、大小和时间，以及观看进度（位置毫秒、时长毫秒、记录时间）、每条记录真实所在目录的 FID 与目录名；文件版本为 4：“最近观看”的条目显示为“目录名 / 原文件名 · 已看 x%”；“追剧中心”根页的剧集分组显示为“目录名 · 上次：<最近一集文件名> · 已看x%”，根目录下或无法确认所属目录的视频各自单列、用各自的原文件名加进度。独立的“已看”标记列表不受“最近观看”100 条上限影响。最近观看的直接目录名取自已知目录与收藏；精彩标记会逐层补全缺失祖先并按账号保存，不用窗口标题猜剧名；剧集分组无法确认目录名时用固定占位“来源目录未命名”（根目录下的影片保留原名）。**不含** Cookie、夸克签名地址或任何视频数据；旧版本（1/2/3）文件可直接读取，读取时不改写，升级写入时才就地变为版本 4。
- 组件与 `quark` 命令行工具共用当前配置目录下的请求冷却状态 `request_guard.json`（只含本机时间与固定原因，不含 Cookie/身份/令牌），跨进程与重启生效：元数据/取链请求发起间隔至少 0.5 秒，收到服务端限流或限制时会暂停新请求。列表接口此时会返回 429/403 并带 `Retry-After`，组件不会因此清除登录凭证或收藏/最近记录；本地健康检查、收藏/最近和退出登录仍然可用。视频数据只检查冷却状态，保持 4 MiB 分段与转发方式，播放转发另有有界预缓冲，按播放位置控制后续取回，不是整集预下载。以上参数是本工具的保守默认值，不能保证账号不被限制。
- 若本机无法写入该冷却文件，组件会停止后续自动请求并报本地存储错误。另一个进程或重启无法得知未写入的冷却，需先修复本机存储并用官方夸克客户端确认账号状态，再重启组件。
- 视频全程不落盘：没有视频文件、没有分片、没有磁盘缓存，只有有限的内存缓冲。
- 组件只在本机后台运行，供当前用户使用；不安装 Windows 服务，不设置开机启动。

## 升级与卸载

- 升级：直接运行新版 `QuarkPotPlayer-Setup.exe`。安装程序按升级处理，保留插件登录状态，无需重新扫码；“收藏目录”“最近观看”、观看进度、“已看”标记与精彩标记也一并保留。
- 卸载：从“设置 → 应用 → 已安装的应用”卸载“夸克网盘 PotPlayer 插件”，或在安装窗口点“卸载”。默认**保留**登录凭证以及“收藏目录/最近观看”，下次安装无需重新扫码；需要彻底清除时，在安装窗口勾选“卸载时同时清除插件凭证”，凭证和这些本地记录（含“已看”标记与精彩标记）会一起删除。
- 登录过期不会被自动清空：凭证失效只会要求重新扫码，“收藏目录”“最近观看”“已看”标记与精彩标记保持原样；显式退出账号也保留该账号的本机记录。需要删除全部账号及其记录时，使用卸载时的清除选项。
- 卸载只删除插件自己的文件，不会动 `quark` 命令行的登录状态。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 扫码窗口没有出现 | 退出 PotPlayer 后重新打开扩展入口；若仍没有，重新运行安装程序修复组件 |
| 扫码后目录没有立即刷新 | 重新进入一次“夸克网盘”入口，或按刷新键重新加载目录 |
| 提示未登录 / 登录过期 | 重新进入入口，在弹出的扫码窗口重新扫码 |
| 某个文件不在列表里 | 只有文件夹和视频文件会显示；确认文件扩展名属于常见视频格式 |
| 目录里的视频没有下一集 | 同一目录下需有多个视频文件；非视频文件不计入选集 |
| 播放失败或中途中断 | 确认网络可用；改用较小的文件或稍后重试。组件会在取链失效时自动重新获取一次 |
| 提示请求过于频繁 / 访问受限（429/403） | CLI 与组件使用本机共享冷却状态，新请求在本地被暂停并带 `Retry-After`。等冷却结束后重试，并用官方夸克客户端确认账号状态；不要清除插件登录凭证或收藏/最近记录 |
| 列表里没有“搜索网盘/收藏目录/最近观看/追剧中心/插件管理” | 确认已升级到带这些入口的版本，并重新进入“夸克网盘”入口；必要时重启 PotPlayer |
| 搜索不到文件 / 搜到很多无关项 | 搜索按文件名匹配整个网盘；换一个更短或更准确的关键词再试 |
| 收藏的目录打不开 | 该目录可能已在网盘里删除或移动；在同一目录页仍可选“取消收藏当前目录”把它移除 |
| 最近观看里的条目没有接上次进度 | 进度按“窗口进程 + 逻辑地址”匹配同一文件；保存位置不足 15 秒、已接近片尾、文件被换成不同大小/时长，或由多个播放器实例同时打开时，会从 0 开始 |
| 播放中途关掉再打开没有回到上次位置 | 组件每 10 秒及暂停/切换/关闭时保存一次；刚播放不足 15 秒即关闭的片段不记进度 |
| 目录首屏没有“继续观看/剧集观看状态”两行 | 该目录没有可识别的视频文件，或该目录状态读取失败（此时不影响正常浏览）；下拉刷新或重新进入该目录再试 |
| “追剧中心”里找不到某集 | 根页面只按本机“最近观看”记录（最多 100 条，**含已看完的**）按父目录 FID 分组，不扫盘；某集的记录被挤出 100 条上限或被“删除本条观看记录”删除后就不会再出现在根页面（该目录只剩这一条记录时分组也一起消失）。进入分组页会重新读取该目录一次、列出目录里全部视频（含已看完的），与是否有本机记录无关；本机扁平列表（`/v1/continue`）只列未看完的，追剧中心则含已看完的。标记“未看”只清除该集的已看标记与续播点，**不会**恢复已被删除或挤出上限的记录 |
| “追剧中心”里分组名字不对，或同一个文件夹分成多条 | 分组按视频真实所在的父目录 FID 区分，同名但不同的目录会分开；目录名只取自组件已浏览过的目录或“收藏目录”，无法确认目录名时分组显示固定占位“来源目录未命名”（不猜剧名）；根目录下或无法确认所属目录的视频各自单列、用各自的原文件名 |
| 删除了某条观看记录后它又出现 | 删除只移除本机记录，不影响网盘文件；“操作”行删除后旧会话不会写回，只有再次显式播放同一视频才会重新记录 |
| 追剧中心分组页没有“下一集” | 只在两种情况出现并显示“已到最后一集 · 返回”（不会回到第一集重播）：本机最近观看的那一集已是本次目录清单里的最后一集；或本机没有该目录可用的观看记录（记录不存在，或记录文件已被换成不同大小而被忽略）且清单里每一集都已看。清单里还有未看完的集时，即使没有最近记录也会给出第一集未看的。目录为空或只剩非视频文件时只显示“该目录没有视频 · 返回”，不按“最后一集”处理 |
| 加不了精彩标记 / 精彩标记跳转失败 | 添加需要当前范围内有唯一正在播放的视频；未播放视频可从标记列表自动打开并跳转。多实例或本机缺少原生读取能力时会失败（删除与重命名仍可用）；文件大小或时长变化会使旧标记无法跳转 |
| 目录里没有“精彩标记”或“标记当前时间点” | 仅有视频文件的目录展示；全局集中管理入口始终在根分类和插件管理标签页中 |
| 卸载后有残留 | 先退出 PotPlayer，再从“插件管理 → 安装管理”查看实际插件目录并处理残留；“收藏目录/最近观看”在 `%APPDATA%\quark-drive-cli\potplayer` 下，需要时一并删除 |

## 首版不包含

分享转存、影视海报库、转码；视频落盘缓存。字幕方面：内嵌字幕/音轨保留原生解码与切换，同目录外挂字幕需在原生“字幕搜索”里手动选择（不自动加载），插件自身不写字幕或视频文件。断点续播仅在 Windows 上通过 PotPlayer 原生读取能力实现；其它平台的 CLI 不受影响。

## 目录层级、自动已看与有限缓冲

- 网盘目录中的“..”携带真实父目录 FID，逐级返回；父目录信息读取失败时显示重试提示，不跳到根目录。根目录不显示重复的上一级入口。
- 每次可信原生采样的观看位置超过总时长 **90%** 后，自动保存“已看”标记（恰好 90% 不触发），下次刷新剧集状态可见。无有效时长、文件身份不匹配或同视频多实例冲突时不自动标记。手动已看/未看仍可使用；播放继续超过阈值会再次触发自动规则。
- `/影视/电视剧/蒸蒸日上/4K/04.mkv` 显示剧集“蒸蒸日上”，视频“蒸蒸日上/4K/04.mkv”，分类列为“电视剧”。4K、1080P、2160P、蓝光等版本层向上查找；电视剧、电影、动漫、综艺、课程和“影视”等分类/容器层不会加入剧名。同一真实剧集目录的不同版本归在同一组，不同 FID 的同名剧集仍分开。
- 目录祖先保存在每个账号的 `directories.json`；旧标记首次补全可能需要读取少量父目录详情，之后复用缓存，不递归扫描整份网盘。网络、登录或冷却导致补全失败时仍保留本地标记并显示提示。
- 视频数据不设置下载速率上限，按最大 4 MiB 的串行 Range 取回并立即转发。前方预缓存上限是视频总大小的 **20%**；达到上限后暂停，剩余缓存降到总大小的 **10% 或以下**才恢复，全速补到 20% 后再次暂停。实际速度取决于网盘和网络；暂停补缓存期间显示的速度降低是正常现象。
- 按可信原生播放进度换算已消费字节，可变码率下是估算；连续、并发 Range 与文件尾索引读取共用同一份预算，重叠字节不重复计算。尚无可用播放时钟时先按网络原速传输最多 20%，之后等待有效进度，不再按时间或固定 MiB/s 补充。拖动进度后按新位置计算，关闭/换片/切换账号停止旧流。组件不创建视频文件或磁盘缓存；播放器自身的缓存设置仍由 PotPlayer 管理。
- 启动解析期间，播放器可能暂时报告旧文件或空文件名，此时继续按上述启动预算供给数据；确认当前视频播放后再切走或停止，才终止旧流。避免首个数据块发出后误断连接，导致“服务器已关闭或地址错误”。
- 程序默认在 PotPlayer 的 `Plugin/QuarkPotPlayer` 内，下载的安装包用完可删除。根目录“插件管理 → 安装管理”可查看版本、路径、打开目录并卸载；默认保留账号与本地观看数据。
