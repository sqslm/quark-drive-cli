### 1. 多选与顺序下载队列

- [x] 在当前目录通过复选框勾选文件或文件夹，点击下载后按列表显示顺序逐项执行；同一时间只运行一个下载。

### 2. 断点续传

- [x] 单文件和目录下载都调用现有 `Transfer.download(..., resume=True)` / `RecursiveTransfer.download_tree(..., resume=True)`，沿用库的 FID、远端版本、目标路径、校验和检查点规则，不另建一套状态文件。
- [x] 增加“停止下载”：请求停止当前任务并清空本次队列；在库已持久化的安全检查点结束，界面收到停止结果后才允许关闭。再次选择原项目和相同保存目录并点击下载，从已有安全检查点继续。
- [x] 远端版本变化、检查点损坏、目标冲突或服务端不支持安全续传时沿用库的拒绝行为，保留状态供检查，不自动覆盖或从头重下。

## 已完成：搜索、筛选与打开保存目录

### 3. 网盘内搜索和筛选

- 关键词、类型和扩展名对已读取结果做本地筛选，保留复选框和同名不同 FID 项目。
- 全盘搜索使用网页版 `file/search`，100 条一页，增量显示；不扫描整个网盘。当前目录及子目录使用精确分页遍历，边扫描边显示结果和目录计数。
- 搜索期间输入、范围、导航和返回目录可用；取消、重复搜索、离开视图使用唯一请求 ID 隔离迟到结果与错误。搜索读取期间禁止下载，取消或完成后恢复。
- 全盘结果路径显示“待定位”；选中查看路径，双击目录定位后进入。父目录链验证后在本次搜索中缓存；全盘结果暂不提供路径排序，子树结果仍支持完整路径排序。
- 首次失败保留原列表，中途失败保留已读结果并标明不完整；不自动回退到全盘遍历。根目录选择“当前目录及子目录”可显式使用扫描方式。
- 搜索独立后台执行，连接 5 秒、读取 10 秒超时；取消不强行中断已发送请求，但不会继续分页或接纳其结果。保留现有请求节流与风控冷却。
- 文件结果按每次 100 行插入 Tk，事件每次最多处理 20 条，允许窗口处理输入与重绘。

- 路径直接传给系统接口，不拼接 shell 命令，目录偏好使用下述独立窗口设置文件。

## 分享链接下载与复选框

- 支持夸克直接分享链接 `https://pan.quark.cn/s/分享ID`，可使用 URL 中的 `pwd` 或单独填写的提取码。预览和进入分享目录只读取分享内容；“我的网盘”切回账号目录。
- 分享视图支持名称与类型的本地筛选，不提供账号全盘/子目录搜索。不能把分享 FID 当作我的网盘 FID 直接下载。
- 每个勾选项下载时转存到本次新建的 `.quark-download-...` 临时网盘目录，使用转存后的账号 FID 下载。结束、失败或停止均清理该目录并定向移除其回收记录，不清空整个回收站，不删除原分享和用户已有目录。
- 清理失败显示临时目录标识及本地下载状态，不冒报全部成功。下载期间需要足够的网盘空间；强制终止进程、失去账号权限或网络不可用时无法保证清理，需检查临时目录和回收站。
- 分享的本地临时目录、部分文件和检查点随本次任务清除，停止后需重新下载；我的网盘下载继续支持断点续传。
- 勾选列与行高亮独立：点击复选框或按空格切换勾选，“全选/取消全选”只作用于当前可见项。筛选隐藏项保留勾选状态，但不参与下载；切换目录或来源清空勾选。下载中禁止修改勾选和来源。

## 已完成：可停止和续传的多线程下载

- “线程数”默认 4，可输入 1–16，1 强制串行；设置通过本地偏好在下次启动恢复，按批次固定，下载中禁止修改。普通文件、目录内文件和分享转存副本都使用同一设置，文件队列仍逐项执行。
- 大于等于 8 MiB 且剩余内容超过一个分段时，按固定 4 MiB 分段，最多保留 N 个待处理段；线程读取，协调线程按顺序写入，同步落盘后更新原有连续前缀账本，不迁移旧检查点。
- 停止或分段失败时等待线程退出，保留已确认前缀；改变线程数后仍可续传。分享仍清除本地暂存和远端临时目录，下次重新下载。
- 服务端忽略 Range 时回退串行。没有强 ETag 的新对象可单次串行下载，但停止后重新下载，不建立虚假续传进度；已有确认前缀仍拒绝追加无版本证据的数据。
- 进度显示本次启用的连接模式和近期速度。普通账号同样使用并发优化，不承诺突破服务端账号限速。
- 离线测试覆盖并发上限、乱序完成、停止恢复、旧检查点、账本写入失败、长度与 ETag 错误及窗口设置冻结。受控测速验证了多连接吞吐收益，真实账号速度需同文件对照。

Electron 主进程管理打包 Python 后端，以协议版本 1 的逐行 JSON 传递 `id/method/params` 和关联响应/事件；preload 仅暴露明确业务接口。Renderer 不接收 Cookie、令牌、签名下载地址或任意 shell/Python 能力，启用隔离、沙箱和 CSP。沿用现有私有配置，任务记录另存并关联账号；授权无法确认时不恢复，分享恢复重新输入提取码。

每版独立更新文档、相关测试、构建和启动验证后自动提交，不推送。远端写操作只在明确测试范围执行，无法实测则明确记录。

### 第二版交付说明

- 独立 Electron 主进程、隔离 preload、React 虚拟文件列表和打包 Python stdio 后端；固定协议版本 1，明确方法白名单和请求 ID，不开放任意执行。
- 登录二维码只作为内存图片发送，不传 Cookie/令牌。昵称读取失败不撤销成功登录；登录成功使旧任务失效，取消/失败保留分享来源。
- 现有浏览、搜索、复选框、分享输入与导航、下载/停止/重试、设置及目录打开已迁移。进度带任务 revision，迟到响应不能覆盖更新结果。
- 配置沿用原私有存储，损坏配置不覆盖，明确报告仅会话生效。文件队列逐项执行，线程数/限速按尝试固定，重试使用当前有效值。
- TypeScript 固定 5.9.3，沿用仓库已有版本；当前 ts-loader 9 不兼容 TypeScript 7 的原生编译器 API。Forge 8 入口使用 `.cjs`。
- 浏览器受控源测试验证万行列表虚拟化、分页取消、复选框单项下载和手工提取码；真实 Electron 验证打包后端、隔离与方法白名单。未进行真实账号写操作或速度测试。

文件页增加新建目录、单项重命名、批量移动、移入回收站、属性、复制路径和右键菜单。操作对话框显示选中项与目标；分享页面不提供网盘修改。后台重新核对 FID、名称、类型、大小和父目录成员关系；目标同名拒绝覆盖，移动拒绝自身及后代。创建确认新 FID，重命名/移动回读，删除确认原目录不再包含选中 FID；未知结果明确提示刷新，不自动重发。登录与传输期间拒绝网盘写操作，批量结果逐项展示并刷新源视图。

离线验证覆盖同名冲突、精确删除及部分失败、禁止移动到子目录、创建回读、重命名与移动路径、根目录保护、分享只读和登录期间写拒绝；浏览器验证新建对话框的名称与目标传递。没有在真实账号修改文件。

### 第四版交付说明与手动测试

- 文件页可上传文件或目录到当前网盘目录；传输中下载/上传选择追加到同一顺序队列。文件队列逐项执行，下载继续使用单文件多线程；上传/下载共用现有载荷限速逻辑。
- 传输页虚拟滚动，提供暂停全部、继续未完成、重试失败、单项取消、分享重新授权和清理已结束记录。取消保留检查点与已完成文件，不删除文件；清理仅移除已完成/取消的任务记录。
- 任务存在独立私有 `downloader/tasks.json`，不保存 Cookie、提取码、分享令牌或签名 URL。使用凭证摘要保守绑定登录上下文；凭证变化后旧任务只读，需重新选择。未完成任务重启后不自动运行，继续前执行只读认证及引擎身份核验；分享恢复重新输入提取码。损坏记录不覆盖，明确提示本次队列仅在窗口有效。
- 上传增加 `should_stop`：初始哈希、分片读取和已确认协议阶段可暂停；恢复用原账本与 ListParts 的长度/MD5 证据，不新增分段状态格式。预上传/哈希/合并/完成等未知受理状态仍拒绝重发；正在返回的元数据请求会先结束。
- 目录上传保留已确认目录 FID 和文件映射；新目录任务不会合并到无关同名目录。运行中追加上传的元数据预检不占用任务进度锁。客户端限制同一用户数据目录只运行一个实例，避免队列记录相互覆盖。
- 已完成离线上传初始停止、分片中断恢复、确认分片跳过、目录映射续传、队列追加与串行上限、等待项取消、重启不自动执行、账号上下文隔离、分享无密码落盘及损坏记录保护测试。真实账号上传、分享清理与服务器速度仍需手动测试。

建议先在网盘专用测试目录中验证：搜索“知否”并取消/重搜；勾选下载且传输时继续浏览、追加任务；暂停后继续；上传小文件及包含子目录的测试目录；关闭后重启检查任务记录和分享重新授权。第四版功能保留；第五版完成后按用户要求暂停第六版，等待手动测试反馈。

### 第五版交付与实测边界

- 修复格式选择后仅剩同一建议的问题：用固定选项下拉代替 datalist，始终提供全部格式、格式分类、无扩展名、自定义格式与清除筛选。自定义格式仍支持多个扩展名及 tar.gz。标题栏统一浅色，使用 Electron 窗口控件覆盖层，保留拖动、最小化、最大化和关闭。
- 创建分享支持单个文件或目录、1/7/30 天或永久有效期、可选四位字母数字提取码；复用 ShareManager 的完整成员/期限/结果核验。本人分享完整分页，复制时读取核验后的链接/提取码，取消按内部 share_id 定向执行，逐项报告。
- 分享浏览保持只读。独立永久转存按钮展示勾选成员和目标目录，后台重新核验 FID、名称、类型、大小，只提交这些直接成员，同名冲突拒绝；原下载临时目录清理行为不变。
- 回收站分页核验记录 ID 与总数。永久删除严格使用 select_mode=2 和选中的 record_id；恢复只提交唯一关联的 FID，恢复前核验原目录与同名冲突，恢复后核验对象身份和记录消失。原目录缺失或重复 FID 拒绝恢复，不猜目标。
- 回收站恢复使用 [cloud-cli 的 recover 实现](https://github.com/Ab-code520/cloud-cli/blob/main/backends/quark/api.go)所示接口；列表/定向删除沿用已有实现与 [quark-auto-save](https://github.com/Cp0204/quark-auto-save/blob/main/quark_auto_save.py)接口。没有真实账号写入测试，接口在当前服务器上的支持情况需实测，不把 Mock 成功当成线上兼容性证据。恢复失败时不尝试其他写接口。
- 写操作与传输/登录互斥，后台保留预留状态避免登录切换或新队列穿插；读取和导航继续可用。未知受理结果不重发，展示结果不完整/未知及可核验的分享链接；用户应先刷新核实。
