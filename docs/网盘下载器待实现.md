## 已完成：搜索、筛选与打开保存目录

### 3. 网盘内搜索和筛选

- 关键词输入对完整列表做本地名称筛选；类型支持全部、仅文件、仅目录，组合筛选不请求网盘。清空条件可恢复完整结果。
- “搜索全盘”搜索整个网盘；“搜索子目录”按文件名搜索当前目录及所有子目录，在根目录发起也搜索全盘。沿用 CLI 的分页遍历和安全限制，后台执行，不建立远端索引。大网盘需要等待扫描完成。
- 搜索结果显示网盘绝对路径，保留同名但不同 FID 的项目。可直接多选下载，保存时保留原名；同名目标冲突沿用库的拒绝规则，不自动改名或覆盖。
- 双击目录结果进入真实目录，返回上级沿真实父目录链导航；“返回目录”回到搜索起点。目录导航清除旧名称与类型筛选；刷新搜索视图重新执行原关键词，刷新普通目录保留其筛选。
- 搜索期间阻止重复搜索、导航和下载；下载期间禁止搜索与筛选改变列表。忽略已不对应当前视图的结果，搜索失败不会提前结束下载队列。

### 4. 打开保存目录

- 增加“打开保存目录”：用户点击后打开 Windows 资源管理器，不在下载结束时自动弹出。
- 批次完成、失败或停止后均可打开所选目录。点击时确认目录仍存在，目录失效或系统打开失败时显示可读错误。
- 路径直接传给系统接口，不拼接 shell 命令，不新增目录偏好或状态文件。

## 分享链接下载与复选框

- 支持夸克直接分享链接 `https://pan.quark.cn/s/分享ID`，可使用 URL 中的 `pwd` 或单独填写的提取码。预览和进入分享目录只读取分享内容；“我的网盘”切回账号目录。
- 分享视图支持名称与类型的本地筛选，不提供账号全盘/子目录搜索。不能把分享 FID 当作我的网盘 FID 直接下载。
- 每个勾选项下载时转存到本次新建的 `.quark-download-...` 临时网盘目录，使用转存后的账号 FID 下载。结束、失败或停止均清理该目录并定向移除其回收记录，不清空整个回收站，不删除原分享和用户已有目录。
- 清理失败显示临时目录标识及本地下载状态，不冒报全部成功。下载期间需要足够的网盘空间；强制终止进程、失去账号权限或网络不可用时无法保证清理，需检查临时目录和回收站。
- 分享的本地临时目录、部分文件和检查点随本次任务清除，停止后需重新下载；我的网盘下载继续支持断点续传。
- 勾选列与行高亮独立：点击复选框或按空格切换勾选，“全选/取消全选”只作用于当前可见项。筛选隐藏项保留勾选状态，但不参与下载；切换目录或来源清空勾选。下载中禁止修改勾选和来源。

## Windows ACL 下载报错修复

- 私有状态和下载部分文件只收紧受保护 DACL，不再同时请求修改所有者；保留当前用户访问限制、只读 ACL 验证及重解析点/不可信状态拒绝规则。
- 无法设置 ACL 时显示固定说明和 Win32 错误码，不显示凭证、SID 或原始系统异常。
- 本机在新建的“仅 Modify、无 WRITE_OWNER”文件和目录上复现原实现错误 5，修复后通过私有 ACL 验证；当前 `E:\TempDownload` 新建对象继承的权限较宽，未直接重现截图现场的失败。状态、传输和凭证相关测试用于验证回归。

## 已完成：可停止和续传的多线程下载

- “线程数”默认 4，可输入 1–16，1 强制串行；设置只在本窗口会话保留，按批次固定，下载中禁止修改。普通文件、目录内文件和分享转存副本都使用同一设置，文件队列仍逐项执行。
- 大于等于 8 MiB 且剩余内容超过一个分段时，按固定 4 MiB 分段，最多保留 N 个待处理段；线程读取，协调线程按顺序写入，同步落盘后更新原有连续前缀账本，不迁移旧检查点。
- 停止或分段失败时等待线程退出，保留已确认前缀；改变线程数后仍可续传。分享仍清除本地暂存和远端临时目录，下次重新下载。
- 服务端忽略 Range 时回退串行。没有强 ETag 的新对象可单次串行下载，但停止后重新下载，不建立虚假续传进度；已有确认前缀仍拒绝追加无版本证据的数据。
- 进度显示本次启用的连接模式和近期速度。普通账号同样使用并发优化，不承诺突破服务端账号限速。
- 离线测试覆盖并发上限、乱序完成、停止恢复、旧检查点、账本写入失败、长度与 ETag 错误及窗口设置冻结。受控测速验证了多连接吞吐收益，真实账号速度需同文件对照。
