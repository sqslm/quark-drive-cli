# 网盘下载器待实现

## 已完成：批量队列与断点续传

### 1. 多选与顺序下载队列

- [x] 在当前目录通过复选框勾选文件或文件夹，点击下载后按列表显示顺序逐项执行；同一时间只运行一个下载。
- [x] 固定本次选项和保存目录，显示当前项、总数、进度及每项成功或失败的结果。单项失败后继续下一项，结束时汇总成功和失败数。
- [x] 下载期间保持窗口响应，阻止重复提交和目录切换；已有目标文件仍按库的规则拒绝覆盖。

### 2. 断点续传

- [x] 单文件和目录下载都调用现有 `Transfer.download(..., resume=True)` / `RecursiveTransfer.download_tree(..., resume=True)`，沿用库的 FID、远端版本、目标路径、校验和检查点规则，不另建一套状态文件。
- [x] 增加“停止下载”：请求停止当前任务并清空本次队列；在库已持久化的安全检查点结束，界面收到停止结果后才允许关闭。再次选择原项目和相同保存目录并点击下载，从已有安全检查点继续。
- [x] 远端版本变化、检查点损坏、目标冲突或服务端不支持安全续传时沿用库的拒绝行为，保留状态供检查，不自动覆盖或从头重下。

## 已完成：搜索、筛选与打开保存目录

### 3. 网盘内搜索和筛选

- 关键词、类型和扩展名对已读取结果做本地筛选，保留复选框和同名不同 FID 项目。
- 全盘搜索使用网页版 `file/search`，100 条一页，增量显示；不扫描整个网盘。当前目录及子目录使用精确分页遍历，边扫描边显示结果和目录计数。
- 搜索期间输入、范围、导航和返回目录可用；取消、重复搜索、离开视图使用唯一请求 ID 隔离迟到结果与错误。搜索读取期间禁止下载，取消或完成后恢复。
- 全盘结果路径显示“待定位”；选中查看路径，双击目录定位后进入。父目录链验证后在本次搜索中缓存；全盘结果暂不提供路径排序，子树结果仍支持完整路径排序。
- 首次失败保留原列表，中途失败保留已读结果并标明不完整；不自动回退到全盘遍历。根目录选择“当前目录及子目录”可显式使用扫描方式。
- 搜索独立后台执行，连接 5 秒、读取 10 秒超时；取消不强行中断已发送请求，但不会继续分页或接纳其结果。保留现有请求节流与风控冷却。
- 文件结果按每次 100 行插入 Tk，事件每次最多处理 20 条，允许窗口处理输入与重绘。

### 4. 打开保存目录

- 批次完成、失败或停止后均可打开所选目录。点击时确认目录仍存在，目录失效或系统打开失败时显示可读错误。
- 路径直接传给系统接口，不拼接 shell 命令，目录偏好使用下述独立窗口设置文件。

## 分享链接下载与复选框

- 支持夸克直接分享链接 `https://pan.quark.cn/s/分享ID`，可使用 URL 中的 `pwd` 或单独填写的提取码。预览和进入分享目录只读取分享内容；“我的网盘”切回账号目录。
- 分享视图支持名称与类型的本地筛选，不提供账号全盘/子目录搜索。不能把分享 FID 当作我的网盘 FID 直接下载。
- 每个勾选项下载时转存到本次新建的 `.quark-download-...` 临时网盘目录，使用转存后的账号 FID 下载。结束、失败或停止均清理该目录并定向移除其回收记录，不清空整个回收站，不删除原分享和用户已有目录。
- 清理失败显示临时目录标识及本地下载状态，不冒报全部成功。下载期间需要足够的网盘空间；强制终止进程、失去账号权限或网络不可用时无法保证清理，需检查临时目录和回收站。
- 分享的本地临时目录、部分文件和检查点随本次任务清除，停止后需重新下载；我的网盘下载继续支持断点续传。
- 勾选列与行高亮独立：点击复选框或按空格切换勾选，“全选/取消全选”只作用于当前可见项。筛选隐藏项保留勾选状态，但不参与下载；切换目录或来源清空勾选。下载中禁止修改勾选和来源。

- 私有状态和下载部分文件只收紧受保护 DACL，不再同时请求修改所有者；保留当前用户访问限制、只读 ACL 验证及重解析点/不可信状态拒绝规则。
- 无法设置 ACL 时显示固定说明和 Win32 错误码，不显示凭证、SID 或原始系统异常。
- 本机在新建的“仅 Modify、无 WRITE_OWNER”文件和目录上复现原实现错误 5，修复后通过私有 ACL 验证；当前 `E:\TempDownload` 新建对象继承的权限较宽，未直接重现截图现场的失败。状态、传输和凭证相关测试用于验证回归。

## 已完成：可停止和续传的多线程下载

- “线程数”默认 4，可输入 1–16，1 强制串行；设置通过本地偏好在下次启动恢复，按批次固定，下载中禁止修改。普通文件、目录内文件和分享转存副本都使用同一设置，文件队列仍逐项执行。
- 大于等于 8 MiB 且剩余内容超过一个分段时，按固定 4 MiB 分段，最多保留 N 个待处理段；线程读取，协调线程按顺序写入，同步落盘后更新原有连续前缀账本，不迁移旧检查点。
- 停止或分段失败时等待线程退出，保留已确认前缀；改变线程数后仍可续传。分享仍清除本地暂存和远端临时目录，下次重新下载。
- 服务端忽略 Range 时回退串行。没有强 ETag 的新对象可单次串行下载，但停止后重新下载，不建立虚假续传进度；已有确认前缀仍拒绝追加无版本证据的数据。
- 进度显示本次启用的连接模式和近期速度。普通账号同样使用并发优化，不承诺突破服务端账号限速。
- 离线测试覆盖并发上限、乱序完成、停止恢复、旧检查点、账本写入失败、长度与 ETag 错误及窗口设置冻结。受控测速验证了多连接吞吐收益，真实账号速度需同文件对照。

Electron 主进程管理打包 Python 后端，以协议版本 1 的逐行 JSON 传递 `id/method/params` 和关联响应/事件；preload 仅暴露明确业务接口。Renderer 不接收 Cookie、令牌、签名下载地址或任意 shell/Python 能力，启用隔离、沙箱和 CSP。沿用现有私有配置，任务记录另存并关联账号；授权无法确认时不恢复，分享恢复重新输入提取码。

### 0.5.2：分享创建、反馈与剩余期限

- 桌面版采用所选根项目核验，避免对目录内部做多轮扫描；原 CLI 默认完整子树核验，scope 受限调用禁止省略子树。保留账号父关系、根集合精确匹配、类型/文件大小、owner、任务完成、不完整快照、链接与期限/提取码核验。未知/部分创建不重发或自动取消。界面明确显示核验的是选中项目。

- 剩余期限直接使用服务端 expired_at（已通过当前账号只读目录请求确认是毫秒时间戳）；兼容秒值，每秒本地刷新，前台/可见性变化及时更新。显示剩余整数小时、不足一小时、过期、永久；悬停显示绝对到期时间。服务端期限缺失显示未知，不能按 created_at+7/30 天推算，因为服务器到期边界可能不等于这种算法。
