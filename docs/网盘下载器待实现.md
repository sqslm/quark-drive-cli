# 网盘下载器待实现

## 已完成：批量队列与断点续传

### 1. 多选与顺序下载队列

- [x] 在当前目录多选文件或文件夹，点击下载后按列表显示顺序逐项执行；同一时间只运行一个下载。
- [x] 固定本次选项和保存目录，显示当前项、总数、进度及每项成功或失败的结果。单项失败后继续下一项，结束时汇总成功和失败数。
- [x] 下载期间保持窗口响应，阻止重复提交和目录切换；已有目标文件仍按库的规则拒绝覆盖。

### 2. 断点续传

- [x] 单文件和目录下载都调用现有 `Transfer.download(..., resume=True)` / `RecursiveTransfer.download_tree(..., resume=True)`，沿用库的 FID、远端版本、目标路径、校验和检查点规则，不另建一套状态文件。
- [x] 增加“停止下载”：请求停止当前任务并清空本次队列；在库已持久化的安全检查点结束，界面收到停止结果后才允许关闭。再次选择原项目和相同保存目录并点击下载，从已有安全检查点继续。
- [x] 远端版本变化、检查点损坏、目标冲突或服务端不支持安全续传时沿用库的拒绝行为，保留状态供检查，不自动覆盖或从头重下。

### 验收

用离线测试验证多选顺序、单项失败后继续、停止后的状态及再次提交的续传参数；通过现有下载器和传输相关测试。构建 `dist/QuarkDriveDownloader.exe`，实际启动窗口，确认多选和停止控件存在。真实账号下载需另行手工验证。

## 已完成：搜索、筛选与打开保存目录

### 3. 网盘内搜索和筛选

- 关键词输入对完整列表做本地名称筛选；类型支持全部、仅文件、仅目录，组合筛选不请求网盘。清空条件可恢复完整结果。
- “搜索全盘”搜索整个网盘；“搜索子目录”按文件名搜索当前目录及所有子目录，在根目录发起也搜索全盘。沿用 CLI 的分页遍历和安全限制，后台执行，不建立远端索引。大网盘需要等待扫描完成。
- 搜索结果显示网盘绝对路径，保留同名但不同 FID 的项目。可直接多选下载，保存时保留原名；同名目标冲突沿用库的拒绝规则，不自动改名或覆盖。
- 双击目录结果进入真实目录，返回上级沿真实父目录链导航；“返回目录”回到搜索起点。目录导航清除旧名称与类型筛选；刷新搜索视图重新执行原关键词，刷新普通目录保留其筛选。
- 搜索期间阻止重复搜索、导航和下载；下载期间禁止搜索与筛选改变列表。忽略已不对应当前视图的结果，搜索失败不会提前结束下载队列。

### 4. 打开保存目录

- 增加“打开保存目录”：用户点击后打开 Windows 资源管理器，不在下载结束时自动弹出。
- 批次完成、失败或停止后均可打开所选目录。点击时确认目录仍存在，目录失效或系统打开失败时显示可读错误。
- 路径直接传给系统接口，不拼接 shell 命令，不新增目录偏好或状态文件。

### 验收

离线测试覆盖子树搜索、完整路径和真实目录链、同名结果、空关键词、大小写匹配、名称与类型筛选恢复、忙碌与过期结果、目录打开及错误；回归现有批量队列、停止与传输安全测试。重新构建 `dist/QuarkDriveDownloader.exe`，启动验证窗口。真实账号搜索、扫码和下载仍需手工验证。
