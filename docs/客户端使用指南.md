# 夸克网盘桌面客户端

面向希望用窗口管理网盘文件的用户。当前版本 **0.5.29**，支持 Windows 10/11 x64。它与 PotPlayer 插件分别安装；无需先装 CLI 或 Python。

## 安装与升级

从 [客户端 Release](https://github.com/sqslm/quark-drive-cli/releases/tag/desktop-v0.5.29) 下载 `QuarkDriveClient-0.5.29-Windows-x64-Setup.exe` 与 `SHA256SUMS.txt`，核对 SHA-256 后运行安装程序。本地交付保存在 `dist/desktop/0.5.29/`。

安装向导支持选择目录与桌面快捷方式，默认安装到当前用户的 `%LOCALAPPDATA%/Programs/QuarkDriveClient`，不要求管理员权限。只需这个安装 EXE，不能从构建目录里单独拷贝客户端主程序。

升级前从托盘退出旧客户端。开始菜单和 Windows 应用列表提供启动与卸载入口；卸载保留用户配置。

## 登录与文件管理

启动后按界面指引使用手机夸克扫码。桌面后端沿用 CLI 的配置与凭证规则；PotPlayer 插件使用独立账号配置。不要在反馈、截图或日志中公开 Cookie。

客户端提供目录浏览、搜索、收藏、回收站、分享管理和文件预览。上传、下载、改名、移动、复制、删除等操作由共享 Python 后端执行；分享视图保持只读，需进入明确的本人网盘目录后再操作目标。

- Ctrl+C / 右键复制记录选中的云端文件或目录；在目标目录 Ctrl+V 粘贴。复制后保留来源。
- Ctrl+X 剪切移动；Ctrl+Shift+C 复制路径。输入框中的快捷键优先处理文本。
- 同名冲突、原目录、自身或子目录等情况会拒绝相关项目，不擅自覆盖。
- 结果不明确的写操作会保留状态并阻止盲目重发；先核验原任务和目标，不通过删除状态强制重试。

## 上传、下载与任务

任务界面区分状态并显示进度、速度、大小和详情，支持筛选与查找。停止、续传和失败重试仍遵守远端身份与本地检查点核验规则。

下载设置支持 1–16 个连接和总限速；0 表示不限速。参数在批次开始时固定，修改设置前需等待当前传输结束。并发只提高客户端传输效率，不绕过账号或服务端限制。

分享下载先经核验转存，再下载并定向清理临时状态；取消或失败后不要手工清空不明账本。目录下载保持目录层级，并拒绝不安全的本地文件名或覆盖冲突。

接口限流会触发共享冷却，登录失效与访问限制分别处理。遇到平台访问限制时先检查官方客户端，不要反复扫码或忙循环重试。

## 从源码运行与构建

需要 Python 3.10+、Node.js/npm；独立 Windows 后端构建还需要 PyInstaller。先在仓库根目录安装 Python 项目，再进入 `desktop/`：

~~~sh
python -m pip install -e ".[test]"
cd desktop
npm ci
npm run typecheck
npm start
~~~

Windows 发行包的构建分为 Python 后端、Electron 运行目录和安装向导三个步骤。先在仓库根目录运行：

~~~sh
python packaging/desktop/build.py --backend-only
~~~

然后进入 `desktop/`，使用相同输出位置打包：

~~~powershell
$env:QUARK_DESKTOP_OUT = 'out/v0.5.29-installer'
npm run package -- --platform=win32 --arch=x64
npm run make:installer
~~~

安装器编译需要 Inno Setup 7；未安装到默认位置时通过 `ISCC_PATH` 指定 `ISCC.exe`。最终单文件安装包在上述输出目录的 `wizard/`，验收后只保留安装包、构建来源与校验清单；运行目录可以重新构建。

`npm test` 包括受控浏览器及 Electron 检查，需要已生成的 `.webpack` 前端/主进程产物和可用浏览器环境。不要把类型检查或离线测试当作真实网盘账号验收。
