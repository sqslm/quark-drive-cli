# 夸克网盘下载器开发计划

## 当前目标与验收

交付 Windows 10/11 x64 可直接运行的独立 `dist/QuarkDriveDownloader.exe`。窗口完成“登录 → 浏览或搜索我的网盘 → 多选文件和目录 → 选择本地保存目录 → 顺序下载”，并提供停止后断点续传和打开保存目录。无需系统安装 Python，不依赖源码目录。

验收确认：共享 CLI 登录；目录能进入和返回；名称与类型筛选不请求网盘；搜索当前目录及其子目录，结果显示完整路径并可下载，目录结果可进入且返回真实父目录；多选按显示顺序下载，单项失败后继续；停止时保留库的安全检查点；下载与搜索期间窗口响应、禁止冲突操作；已有目标拒绝覆盖，认证、网络、本地错误明确提示；EXE 可启动并显示控件。真实扫码、账号搜索和远端下载仍需真实账号手工验证。

## 范围与方案

- 仅处理用户自己的网盘。分享链接导入与转存、自动覆盖、实时暂停、账号管理不在当前范围。
- 共用 `auth.QRLogin`、`auth.get_cookie` 和 CLI Cookie 文件，不增加凭证文件。目录浏览沿用 `Files.list_all`，搜索沿用 `RemotePaths.walk` 的分页、路径和循环检查；下载沿用 `Transfer.download` 与 `RecursiveTransfer.download_tree`，始终 `resume=True`。
- 使用已有 Tkinter 窗口。网络和下载由同一个后台线程顺序处理，通过队列与 `after()` 回传结果；本地筛选只作用于完整列表，不产生网盘请求。搜索路径仅用于展示和导航，下载仍用真实 FID 和原文件名；不同目录的同名文件下载到相同目标时沿用库的冲突规则。
- 批次固定本次选择和保存目录；停止清空未开始项，等待当前项安全结束后恢复操作。搜索时禁用重复搜索、导航与下载；下载时禁用搜索与筛选，保持批次稳定。
- “打开保存目录”由用户点击触发，验证目录仍存在，通过 Windows 原生目录打开接口处理路径，不拼接 shell 命令。
- 使用现有 PyInstaller `--onefile --windowed` 构建脚本，不引入新 GUI 框架、远端 API、索引或持久化配置。

## 开发与验证方式

1. 修改前核对代码、相关测试和 Git 状态，保护已有工作区修改。
2. OMP Worker 在独立文件范围开发搜索后端与窗口交互；不执行 Git 提交或远程操作。主会话审查接口、Diff 和行为，统一整合。
3. 离线测试覆盖搜索范围、同名结果、目录导航、名称与类型筛选、错误及忙碌状态、保存目录打开，并回归批量下载、停止、断点续传及传输安全行为。
4. 构建独立 EXE，检查产物、体积和 SHA-256，实际启动窗口验证。账号操作的离线限制如实报告。
5. 更新 README 与待实现文档；必要验证通过后，仅暂存本轮相关文件，主会话执行 Conventional Commits 提交，不推送远端。

## 完成标准

实现、相关离线测试、简短使用文档和独立 EXE 均交付；窗口启动实际检查通过；凭证和签名下载链接不进入日志或错误提示；不修改下载器无关功能。
