# 夸克网盘下载器开发计划

## 目标与验收

交付 Windows 10/11 x64 可直接运行的独立 `QuarkDriveDownloader.exe`，用窗口完成“登录 → 浏览我的网盘 → 选择一个文件或目录 → 选择本地保存目录 → 下载”。无需系统安装 Python，不依赖源码目录。

验收时确认：扫码登录或已有 CLI 登录可用；目录能进入和返回；选中文件下载到所选目录并保留原名，选中目录递归下载且保留目录名；下载时窗口可响应并显示状态与进度；已有文件冲突及认证、网络错误能明确提示；构建后的 EXE 可启动并显示窗口。远端真实下载需要账号和测试文件，无法离线代替验证。

## 范围与方案

- 只处理用户自己的网盘。分享链接、转存、多任务队列、自动覆盖、暂停恢复、账号管理不在本次范围。
- 沿用现有 `auth.QRLogin` 与 `auth.get_cookie`，共用 CLI 已保存的 Cookie；不新增一套凭证文件。沿用 `Files.list_all`、`Transfer.download`、`RecursiveTransfer.download_tree`，保留库中的路径检查、请求保护和下载安全规则。
- 使用项目已有的 Tkinter；界面更新只在 Tk 主线程，网络和下载放到后台线程，用队列与 `after()` 回传结果。下载期间禁用重复启动下载，退出时避免留下不完整的目标文件。
- 用 PyInstaller `--onefile --windowed` 构建 Windows EXE。项目已有 PyInstaller 打包先例，无需引入新的 GUI 框架。

## 实施步骤

1. **核对现有接口和中断留下的草稿。** 检查 `src/quark_cli/auth.py`、`files.py`、`transfer.py`、`recursive.py` 及 `src/quark_cli/downloader/` 中的未提交草稿。只保留对本次功能必要的代码；尤其移除独立凭证存储与重复抽象。
2. **完成窗口。** 新增或收敛 `src/quark_cli/downloader/`：登录入口、目录列表/返回、单项选择、本地目录选择、下载按钮、进度和错误提示。复用现有下载 API，不通过子进程调用 CLI，也不在 UI 线程进行网络请求。
3. **完成可复现打包。** 在 `packaging/downloader/` 放置最小入口/构建脚本，产物固定为 `dist/QuarkDriveDownloader.exe`。补充 README 中的使用与构建方法，并说明 Cookie 与 CLI 共用。
4. **针对性验证。** 为非 UI 决策和后台调用补充必要的离线测试；运行新增测试及现有认证、下载相关测试。构建 EXE，检查文件存在、体积与 SHA-256，启动后确认窗口出现。无法进行的真实账号操作如实列为限制。
5. **主会话验收与提交。** OMP 只交付文件、测试结果和最终摘要，不执行 Git 操作。主会话检查 Diff、必要时派发定向修复，验收通过后仅暂存本任务相关文件并按 Conventional Commits 提交。

## 完成标准

源代码、构建脚本、简短文档和独立 EXE 均已交付；相关离线测试通过；窗口启动经过实际检查；无凭证或签名下载链接进入日志及错误提示；无与下载器无关的改动。
