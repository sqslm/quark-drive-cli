# 夸克网盘下载器开发计划

## 当前目标与验收

交付 Windows 10/11 x64 可直接运行的独立 `dist/QuarkDriveDownloader.exe`。窗口完成“登录 → 浏览或搜索我的网盘，或打开分享链接 → 勾选文件和目录 → 选择本地保存目录 → 顺序下载”，并提供停止下载和打开保存目录。我的网盘下载支持断点续传。无需系统安装 Python，不依赖源码目录。

验收确认：共享 CLI 登录；账号和分享目录能进入和返回；名称与类型筛选不请求网盘；账号搜索结果显示完整路径并可下载，目录结果可进入且返回真实父目录；勾选项按显示顺序下载，单项失败后继续；账号停止时保留安全检查点，分享停止时清理临时目录；下载与搜索期间窗口响应、禁止冲突操作；已有目标拒绝覆盖，认证、网络、本地错误明确提示；EXE 可启动并显示控件。真实扫码、账号搜索和分享远端清理仍需真实账号手工验证。

## 范围与方案

- 支持我的网盘和夸克分享链接。分享预览不转存；下载只将选中项转存到本次新建的临时目录，结束、失败或停止后删除该目录，并定向移除其回收记录，不清空用户回收站。清理失败必须明确提示，不能报告为全部成功。强制终止进程或网络不可用时无法保证远端清理完成，需人工检查提示的临时目录。
- 共用 `auth.QRLogin`、`auth.get_cookie` 和 CLI Cookie 文件，不增加凭证文件。目录浏览沿用 `Files.list_all`，搜索沿用 `RemotePaths.walk` 的分页、路径和循环检查；下载沿用 `Transfer.download` 与 `RecursiveTransfer.download_tree`，始终 `resume=True`。
- 使用已有 Tkinter 窗口。目录、搜索和文件队列由同一个后台线程顺序处理，文件分段使用设置的线程数；昵称独立后台读取并复用请求守卫，所有结果通过队列与 `after()` 回传；本地筛选只作用于完整列表，不产生网盘请求。搜索路径仅用于展示和导航，下载仍用真实 FID 和原文件名；不同目录的同名文件下载到相同目标时沿用库的冲突规则。
- 批次固定本次选择和保存目录；停止清空未开始项，等待当前项安全结束后恢复操作。搜索时禁用重复搜索、导航与下载；下载时禁用搜索与筛选，保持批次稳定。
- 线程数默认 4，可设 1–16，按批次冻结并贯通文件、目录和分享副本。固定 4 MiB 分段，最多 N 个待处理段，由单一写入者保存连续前缀及原有账本；旧串行检查点继续兼容。小文件和不支持 Range 的服务端使用串行；缺乏强 ETag 的新对象只能单次串行下载，停止后重新下载，不建立错误续传记录。进度显示实际启用模式及近期速度。
- 列表通过复选框、空格及全选/取消全选控制下载项，不需要 Ctrl。只下载当前可见的勾选项，筛选隐藏项不会加入批次；切换目录或来源清空勾选。
- 分享下载复用现有分享授权、精确 FID 转存和传输接口，不能将分享 FID 当作我的网盘 FID。临时本地状态随下载结束清除，因此分享停止后重新下载，不跨次续传。分享视图只提供当前列表筛选，不进行账号全盘搜索。
- “打开目录”由用户点击触发，验证目录仍存在，通过 Windows 原生目录打开接口处理路径，不拼接 shell 命令。
- 分享输入接受纯链接、带 pwd 的链接和整段分享文案；识别结果填入独立提取码栏，打开时使用该栏当前值。多链接、冲突提取码必须先解决，不猜测或转存。
- 顶部昵称读取固定账号接口的 data.nickname；启动目录加载后及登录后请求，失败不阻止浏览和下载，重新登录清除旧值并忽略过期结果。
- 沿用 ttk 控件统一按钮；搜索范围配合单一搜索按钮，返回目录只在搜索会话出现，底部集中保存目录、线程数、停止和带勾选数量的下载按钮。
- 新增任务页，显示当前批次的逐项状态与结果；手动重试失败项或继续所有未完成项，保持原顺序、保存目录和分享来源，并跳过成功项。新尝试使用当前线程数，仍拒绝覆盖目标、沿用续传和分享清理。记录仅保留在窗口内，新选择替换记录；成功重新登录后旧 FID 只能展示，不能重试。
- 文件表头支持名称、大小、路径升降序，目录置前、未知大小置后，大小排序不伪造目录体积；本地排序保留 FID 勾选、高亮及焦点，筛选刷新沿用窗口排序，忙碌期间冻结。
- 本地偏好自动记住保存目录、有效线程数、限速和窗口尺寸，存入独立的 downloader/preferences.json，沿用私有原子写入；不保存凭证或任务。目录失效提示重选，尺寸适应当前屏幕；配置读写失败明确提示，仍允许使用窗口。
- 任务页右键提供单项重试和打开原保存目录；已完成目录任务进入其本地子目录。操作保持原来源与目标，忙碌时拒绝操作，完成项及旧登录任务拒绝重试。
- 文件扩展名栏提供常用分组和自定义多个后缀，与名称、类型和排序组合；启用后只显示文件，隐藏勾选不下载。筛选完全本地，刷新保留、导航重置、忙碌冻结；无效输入清空结果并提示，避免下载旧列表。
- 总限速默认 0 不限速，按 MiB/s 输入；复用既有线程安全载荷预算，贯通文件、目录和分享下载。批次固定，重试使用当前值；偏好版本 2 保存限速，兼容旧版本设置。
- 使用现有 PyInstaller `--onefile --windowed` 构建脚本，第一版保持 ttk；第二版迁移 Electron + React + TypeScript，通过逐行 JSON 调用打包 Python 后端，不建立全盘索引。临时分享目录的回收记录使用定向移除接口。

## 开发与验证方式

1. 修改前核对代码、相关测试和 Git 状态，保护已有工作区修改。
2. 由 Codex 直接开发，不使用 OMP；按客户端六版路线图实施，优先交付搜索提速及取消，再迁移 Electron，验证后构建 EXE 并提交。
3. 离线测试覆盖分享精确选项、转存后的下载、成功/失败/停止清理及不删除无关记录，复选框及分享导航；本机验证 Windows 私有 ACL，并回归批量下载、搜索、停止、断点续传及传输安全行为。
4. 构建独立 EXE，检查产物、体积和 SHA-256，实际启动窗口验证。账号操作的离线限制如实报告。
5. 更新 README 与待实现文档；必要验证通过后，仅暂存本轮相关文件，主会话执行 Conventional Commits 提交，不推送远端。

## 完成标准

实现、相关离线测试、简短使用文档和独立 EXE 均交付；窗口启动实际检查通过；凭证和签名下载链接不进入日志或错误提示；不修改下载器无关功能。

## 当前客户端交付边界

六版路线图已完成搜索、Electron 基础客户端、文件管理、上传与持久传输中心、分享与回收站五个阶段，并交付托盘与后台运行、拖拽上传小版。当前 Electron 版本 0.5.10，采用私有任务 JSON 和既有传输账本，禁止重发未知受理状态。按用户要求，本小版验证、构建和提交后暂停，其余功能等待手动测试反馈。Electron 构建入口为 `python packaging/desktop/build.py`，运行包在 `desktop/out/v0.5.10/`；下载器旧版单文件 EXE 保留。

已具备常用文件夹、可点击路径、详情自动大小单位，以及移动/删除/重命名的请求复用与交互式间隔优化。多标签不实现。收藏私有存储按凭证摘要隔离，打开重新核实当前父链；账号或凭证变化不直接沿用旧目录。移动按新目标列表整批核验，批量删除一次提交并按新父目录列表核验。交互文件请求间隔 0.1 秒，扫描/传输沿用原间隔，共享持久冷却；未知写结果不重发。

当前小版收紧工具栏，将选中项操作集中到右键/行内更多，筛选按需展开；账号入口覆盖退出、切换及官方扫码、手机验证码、微信登录。网页版登录使用隔离的内存 BrowserWindow，会话 Cookie 由主进程直送 Python 的内部白名单方法，Renderer 不能直接导入凭证。验证成功后接入并选择本次保存的凭证，取消/验证失败保留原登录。退出清除共享本地扫码凭证并持久化退出状态，防止重启后自动采用环境旧账号。传输/写操作时禁止账号变更，旧任务和分享句柄不能误用于新登录。官方两种网页窗口已实际打开、选中方式并关闭验证；最终验证码/微信登录和绑定需要本人复测。完成后暂停。
